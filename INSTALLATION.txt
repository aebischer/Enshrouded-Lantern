BELT LANTERN 0.1.29-dev — WINDOWS X64
Development build — no compiler required for the release ZIP

REQUIRES: Enshrouded ModLoader 0.6.12 or newer.
https://github.com/aebischer/Enshrouded-ModLoader/releases
Install the loader first using its INSTALLATION.txt.

1. Close Enshrouded and back up your saves.
2. Extract the complete Lantern ZIP.
3. In Steam: Enshrouded -> Properties -> Installed Files -> Browse.
4. Merge the supplied Mods directory into the game directory beside enshrouded.exe:

Enshrouded/
  enshrouded.exe
  dinput8.dll                    supplied by the loader
  Mods/EnshroudedModLoader/
    lantern/
      lantern.dll
      lantern.dll.mod

Do not create Mods/Mods or copy the files into ModLoader. No additional model
or texture installation is required. When updating, replace only the DLL and
manifest; preserve equipment-markers and all other saved data.

5. Start the game -> Edit world -> MODS -> Lantern -> Enable.
6. In manual crafting / Essentials, craft:
   Belt lantern: 2 iron bars + 1 placeable candle.
   Gilded lantern: 2 gold bars + 1 placeable candle.
7. Open Character (N), click the dedicated Lantern slot and equip an inventory
   lantern using the native selector. Alternatively, right-click a lantern in
   the bag (B) and choose Equip. Unequipping requires a free inventory slot.

Both variants share one slot, separate from the rings. The model follows the
character's waist and provides native lighting without an exposed flame.
Gilded light parameters: radius 187.5, intensity 100. The simple light is unchanged.

SAVE DATA: back up character saves. Equipped lanterns are committed in the
character file; new saves do not require external equipment markers and do not
increase bag capacity. Old markers are retained only for migration.
Loading and saving without the mods can discard unknown custom items, even in
the bag. Keep a backup before disabling or uninstalling mods.
Already enlarged inventories need a separate verified repair; this update does
not silently truncate overflow items. See docs/INVENTORY_STORAGE.md in the source.

Supported enshrouded.exe SHA-256:
5D9EF2F140B8ED49E30DBEE655841B89D08BAEC20F799A1817E171A18A850C77
Solo use only; other game versions, multiplayer, dedicated servers and tombstone
interactions are not validated. The main-menu character does not show the
lantern before a world enables the mod. The in-world Character preview is supported.

All 15 game interface languages are included. Documentation uses English.
Offline localization, equipment and content tests pass; visual/linguistic review
of the new translations remains a manual in-game check.
Use SHA256SUMS.txt and Get-FileHash to verify release contents.
Sources and public downloads: https://github.com/aebischer/Enshrouded-Lantern

Do not keep duplicate old and new package folders.
