# Lantern integration history

The prototype's pending equipment work is now implemented. The dedicated character slot opens the native filtered equipment selector, supports inventory-context Equip, preserves actual item instances when swapping and stores equipped data through the native inventory path with equipment markers.

The current README documents crafting, both models, lighting, save markers, 15-language coverage and limitations. This page is an index to the original engineering notebook, whose statements such as “not installed” describe earlier prototypes only. Native offsets, diagnostics and trial designs are retained in the archive rather than presented as current instructions.
